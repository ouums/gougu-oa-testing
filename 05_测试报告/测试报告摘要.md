# 勾股OA 6.1.2 测试报告（公开摘要）

> 被测对象：第三方开源 OA 系统 **勾股OA 6.1.2**（ThinkPHP 8 + MySQL）的本地部署实例。
> 本报告是个人测试实践的结果摘要，**不是**该产品的官方测试结论。

## 1. 结论

| 指标 | 结果 |
|---|---|
| 设计用例 | **135 条**（权限 55 / 审批流 35 / 合同 30 / 薪资 15） |
| 执行 | 135 条全部执行 |
| 通过 | **112 条** |
| 已知缺陷（`xfail(strict=True)`） | **23 条** |
| 失败 / 错误 | **0 / 0** |
| 通过率（不含预期失败） | 82.96% |
| 缺陷 | **20 条**（严重 9 条：A 3 / B 6） |
| 观察项 | 9 条（不计入缺陷） |
| 性能样本 | 3 个读接口 × 10/20/50 并发，**91,809 个样本，0 失败** |

严重缺陷集中在**访问控制**：接口鉴权缺失、水平越权、请求参数未受限。
其中 2 条属于接口整体绕过权限，影响面大于单条业务接口。

## 2. 测试范围

| 模块 | 用例数 | 覆盖重点 |
|---|---:|---|
| 权限体系 | 55 | 角色组 / 职位 / 账号 / 权限节点 / 界面与接口一致性 |
| 审批流 | 35 | 建单、提交、审批、退回、撤回、会签 / 或签 |
| 合同管理 | 30 | 新建、编辑、状态流转、金额与税点边界 |
| 薪资管理 | 15 | 工资条可见性、明细增删改、合计重算、越权读取 |

不在范围内：移动端、Firefox / Edge / Safari、第三方地图与企业微信集成、生产环境。

## 3. 测试方法

- **接口优先**：每条用例都真实发请求、真实比较返回值，不读取历史结果 JSON 冒充执行。
- **统一判定口径**：一律解析响应体 JSON 的 `code`，不看 HTTP 状态码。该系统的权限拦截
  返回 HTTP 200 + `code=405`，只看状态码会把“被拦截”误判为“正常”。
- **UI 对照法**：疑似接口越权只有在“界面拒绝同一用户、接口却放行”时才确认，
  避免把设计如此的功能误报为缺陷。
- **夹具生命周期**：会话级 fixture 负责搭建与回收，跑完回读核对，库回到基线。
- **已知缺陷固定为回归探针**：`xfail(strict=True)`，缺陷修复后 XPASS 会直接判失败，
  提醒回来销账。

## 4. 性能测试

| 项 | 内容 |
|---|---|
| 接口 | 审批列表、合同列表、员工列表（均为只读） |
| 并发 | 10 / 20 / 50 三档，每档 ramp 10 s + 稳态 60 s |
| 样本 | 91,809 |
| 失败 | 0 |
| 结论 | 吞吐在 10 并发即到顶，继续加压只增加响应时间 |

根因定位为部署配置：PHP-FPM 的 `pm.max_children=5`，并发请求在进程池排队。
这是**部署配置问题，不是产品缺陷**；更换部署参数后曲线会变化，因此报告不设绝对 TPS 阈值，
只描述梯度趋势。

| 项 | 内容 |
|---|---|

| 工具 | pytest、requests、allure-pytest、Playwright、JMeter 5.6.3、openpyxl |

## 6. 局限

- 只在**单个本地实例**上验证，结论不外推到其他版本、其他部署或其他数据规模。
- 性能数字来自单机 WSL2（应用、数据库、压测机同机同盘），不具备迁移性。
- 只覆盖 Chrome；未做兼容性与移动端测试。
- 缺陷复现步骤与原始证据不随仓库发布，见 [缺陷摘要](../04_缺陷报告/缺陷摘要.md)。
